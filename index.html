API REST de veterinaria

API REST para gestionar mascotas, dueños, veterinarios y turnos, persistida en SQL Server con Entity Framework Core.

  • CRUD de mascotas y veterinarios con controllers y status codes correctos.
  • Route constraints y model binding explícito desde ruta, cuerpo y query string.
  • Filtros combinables por query string.
  • Validación con Data Annotations más reglas de negocio entre campos.
  • Persistencia real con Entity Framework Core + SQL Server (migraciones).
  • Documentación interactiva con Scalar.

Tecnologías: C#, .NET 10, ASP.NET Core Web API, EF Core, SQL Server

API REST de biblioteca

API REST para gestionar libros, socios y préstamos conectada a SQL Server con Entity Framework Core, acompañada de un cliente de escritorio en WPF que la consume.

  • CRUD completo de libros, socios y préstamos con persistencia real en base de datos.
  • Uso de Entity Framework Core para el mapeo objeto-relacional y migraciones.
  • Cliente WPF con pestañas por entidad, consumiendo los endpoints de la API.

Tecnologías: C#, .NET 10, ASP.NET Core Web API, EF Core, SQL Server, WPF, XAML
